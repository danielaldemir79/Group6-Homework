## 🚀 Hur man använder projektet

### Steg 1: Öppna Project Hub
Öppna `index.html` i din webbläsare för att se alla tillgängliga funktioner.

### Steg 2: Navigera mellan funktioner
Klicka på "Öppna Funktion" för att testa olika sökfunktioner:
- **Förnamn sökning** - Sök efter specifika förnamn
- **Åldersberäkning** - Beräkna och visa personers ålder
- **Efternamn filter** - Filtrera på efternamn
- **E-post filter** - Sök efter e-postadresser
- **Ålder filter** - Filtrera baserat på ålder
- **Dynamisk sökning** - Kombinerad sökning med dropdown-meny

### Steg 3: Data
Alla funktioner använder samma `people.json` fil med testdata om personer.
